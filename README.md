## Versiebeheer via GitHub

Net zoals bij Git, kunnen we vanuit GitHub aan versiebeheer doen.

1. Open je repository op GitHub.
2. Klik in de bestandslijst op `README.md`.
3. Klik rechtsboven op het potlood-icoon om het bestand te bewerken.
4. Typ in het tekstvak wat nieuwe informatie (bijv. iets over jezelf).
5. Klik bovenaan op **Preview** om je wijziging te bekijken.
6. Vink **Show diff** aan om nieuwe regels in groen te zien.
7. Klik op **Commit changes…**.
8. Vul bij **Commit message** een korte, duidelijke boodschap in (bv. “Info over mezelf toegevoegd”).
9. Kies onderaan voor **Nieuwe branch aanmaken en pull request maken**.
10. Klik op **Commit changes** om te bevestigen.
